> 久等了

先解释一下为什么两个月没更新——**账号搞丢了**。

GitHub 那边折腾了好一阵子才找回来，中间一度以为这个博客要就此搁置。好在最终还是找回了账号，博客也得以继续。以后不出意外的话，会持续更新下去。

这次找回来之后，第一件事就是把博客底层的资源库全部梳理了一遍。毕竟两个月过去，很多库都有了新版本，旧的 CDN 也有些不稳定。索性来一次大换血，把能更新的都更新了。

## 这次改了什么

### 一、jQuery 2.1.3 → 4.0.0

jQuery 从古老的 2.1.3 直接跳到了最新的 4.0.0，跨了三个大版本。

升级过程还算顺利，因为项目里对 jQuery 的使用比较基础，主要是 DOM 操作和事件绑定，没有用到被移除的 API。唯一需要注意的是 4.0 移除了一些过时的方法，但这个博客用不到，所以没什么影响。

### 二、Font Awesome 4.7.0 → 6.4.0

图标库也升级了，从 4.7.0 升到 6.4.0。

6.x 版本引入了新的图标命名规范，比如 `fa fa-home` 变成了 `fa-solid fa-home`。不过好在有 `v4-shims.js` 这个兼容垫片，旧的类名依然能用，省去了大量改模板的工作量。

为什么不升到最新的 7.x？因为 7.x 有 breaking changes，而且 6.4.0 已经够用了，稳定优先。

### 三、MathJax 3.2.2 → 4.1.3

数学公式渲染库升级到了 4.1.3。

这个改动稍微多一点，因为 MathJax 3 → 4 的配置方式有变化：

- 配置对象从 `MathJax.Hub.Config` 变成了直接设置 `window.MathJax`
- SVG 渲染的 `scale` 参数从 `0.9` 改成了 `scale: 0.9`
- CSS 选择器从 `.MathJax_SVG_Display` 变成了 `mjx-container[display="true"]`

公式字体大小调到了 0.9 倍，测试下来这个比例和正文最搭。

### 四、CDN 统一为 jsDelivr

之前博客的 CDN 来源比较杂：cdnjs、bootcdn、unpkg 都有。这次全部统一到了 **jsDelivr**，原因很简单：

- 国内访问速度稳定
- 支持 npm 包直链
- 可以指定精确版本号

统一之后，Service Worker 的预缓存列表也更好维护了。

### 五、移除 IE 兼容库

既然都 2026 年了，IE11 也早就不支持了，干脆把这些老古董删掉：

- **fastclick**：解决移动端 300ms 延迟，现代浏览器已经原生支持
- **html5shiv**：让 IE9- 识别 HTML5 标签
- **respond.js**：让 IE9- 支持 CSS3 媒体查询

删完之后页面加载速度还快了一丢丢。

### 六、anchor-js 4.3.1 → 5.0.0

文章标题旁边的锚点链接用的 anchor-js，从 4.3.1 升到了 5.0.0。API 兼容，不需要改调用代码。

### 七、gitalk 版本固定

评论系统 gitalk 之前用的是浮动版本 `gitalk@1`，每次加载都可能拉到不同的小版本。这次固定到了 `gitalk@1.8.0`，避免意外引入 breaking changes。

### 八、告别 Less

最后一个大动作：**彻底移除了 Less**。

之前博客的样式是用 Less 写的，然后通过 Grunt 编译成 CSS。但实际上我已经很久没改过 Less 了，都是直接改编译后的 CSS。既然如此，Less 这层就没什么存在的意义了。

这次把 `less/` 目录整个删掉，Gruntfile.js 里的 less 任务也清理掉，`grunt-contrib-less` 依赖也一并移除。以后直接编辑 `css/style.css` 就行，简单直接。

为了方便阅读，还把 `style.css` 用 Prettier 格式化了一遍，2 空格缩进、120 列宽，看着舒服多了。

## 没动什么

**Bootstrap 3.3.2 保持不变**。

虽然 Bootstrap 已经出到 5.x 了，但 3 → 5 是大版本升级，网格系统、导航栏、响应式工具类全部重写。Hux 主题又深度定制了 navbar 和 pager，升级的风险远大于收益。

稳定压倒一切，没必要为了更新而更新。

## 总结

这次升级涉及 8 个资源库，删除了 3 个过时依赖，移除了 Less 构建链。所有改动都已经推送到 main 分支，博客运行正常。

以后会持续更新，写写技术、写写生活。如果你也在用 Hux 主题，希望这篇文章能给你一些参考。

> 博客这东西，贵在坚持。
